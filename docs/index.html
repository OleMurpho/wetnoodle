wetnoodle — memory you can check

A search index over PubMed abstracts. Every result is a real paper: title, journal, year, PMID. Nothing here is generated, so any answer can be checked against its source.

Typed questions use keyword search (BM25) — a browser has no embedding model. The examples below use the embedding search this project actually ships.

Examples run cosine similarity in your browser over vectors computed locally by nomic-embed-text (256 dims, int8-quantised). Data: PubMed abstracts via NCBI E-utilities, NLM public data. Each example is a real paper title, and the page reports the rank of the abstract it came from. This page has no embedding model of its own — a browser cannot run one — so typed searches are keyword-only (BM25) and the examples replay vectors computed locally beforehand. We drew 59 titles across the corpus, kept the 46 long enough to be a fair query, and 30 of those 46 returned their own abstract in the top three. The examples above are drawn from those 30: that is curation, not a claim about the other 16.
