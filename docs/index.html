wetnoodle — retrieval you can check

A session-memory archive for Hermes Agent: local embeddings, sqlite, no cloud, no API key. This page runs the real search maths in your browser over a real index.

green chips run vector search — their query embeddings were computed locally and shipped with the page, so the cosine ranking you see is genuine. Typed text falls back to BM25 because a browser has no embedding model.

Corpus: a synthetic archive (fictional “Orchard” robotics project, 51 turns) — no real user data. Index: dimensions, nomic-embed-text, vectors L2-normalised.
Passages outlined in green contain the string that answers the question, so you can see the answer's rank rather than take the ranking on trust. Some queries put it below rank 1 — that is what retrieval actually looks like, and why the repo ships an eval harness instead of a marketing claim.
